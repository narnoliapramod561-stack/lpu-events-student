# LPU Events — Subcategory Default Images

Production default images for event subcategories.

## Asset specification
- Canvas: 1920 × 800
- Aspect ratio: 2.4:1
- Format: WebP
- Visual direction: premium cinematic LPU Events style
- School subcategories are intentionally excluded from this folder.

## Naming convention
`<category-key>_<subcategory-key>.webp`

Examples:
- `academics_seminar.webp`
- `academics_workshop.webp`
- `innovation_hackathon.webp`
- `student-clubs_tech-clubs.webp`

## Current taxonomy scope
All non-School subcategories from the canonical taxonomy are intended to have one dedicated asset.
